# dkremsa/tap

```sh
brew install dkremsa/tap/pacer
```

- [pacer](https://github.com/dkremsa/claude-pacer) — menu-bar pace for your AI coding subscriptions: will they last
  until their reset, and what to change if not. Claude Code, Codex, Antigravity and Cursor.

Renamed from `claude-pacer` at v2.0.0, when it stopped being Claude-only. The old name still resolves here, but an
**already-installed `claude-pacer` does not upgrade across the rename** — `brew uninstall claude-pacer` first. The
repo, the bundle id and the data dir keep the old name on purpose.
